# 安卓广告 SDK 需求说明

## 一、项目目标

开发一个 **Android 广告 SDK**，用于在合作方 App 中展示 **HTML5
游戏广告**。 广告点击后可以跳转到 **HTML5
游戏页面**，用户可以直接在线玩游戏。

SDK 主要用于 **小游戏广告分发与变现**。

------------------------------------------------------------------------

# 二、核心功能需求

SDK 需要支持以下广告类型：

## 1 Banner 广告

-   页面底部或顶部展示
-   固定尺寸
-   支持自动刷新

示例尺寸： 320x50\
320x100\
728x90

功能： - 自动加载广告 - 自动轮播 - 点击跳转游戏

------------------------------------------------------------------------

## 2 卡片式广告

单个游戏卡片包含： - 游戏图标 - 游戏名称 - 游戏描述 - 试玩按钮

点击卡片：打开游戏

------------------------------------------------------------------------

## 3 信息流广告

特点： - 嵌入到列表中 - 类似内容推荐

结构： - 游戏封面 - 游戏名称 - 评分 - 简介 - 试玩按钮

支持： - RecyclerView - ListView

------------------------------------------------------------------------

## 4 多联卡片广告

特点： - 横向滑动 - 多个游戏卡片

示例：

| 游戏A \| 游戏B \| 游戏C \| 游戏D \|

支持： - 横向滑动 - 自动滑动

------------------------------------------------------------------------

# 三、广告点击行为

点击广告后支持两种打开方式

## 方式1：系统浏览器

流程：

广告点击 → 打开浏览器 → 进入游戏URL

示例： https://game.example.com/play/123

优点： - SDK实现简单 - 兼容性好

缺点： - 用户离开APP

------------------------------------------------------------------------

## 方式2：SDK内全屏游戏

推荐使用 **Android WebView**

原因： 1. 稳定\
2. 兼容所有APP\
3. 不依赖Chrome

WebView配置：

setJavaScriptEnabled(true)\
setDomStorageEnabled(true)\
setMediaPlaybackRequiresUserGesture(false)\
setAllowFileAccess(true)\
setMixedContentMode(MIXED_CONTENT_ALWAYS_ALLOW)

游戏Activity：

GameActivity

功能： - 全屏模式 - 返回按钮 - 加载动画 - 错误处理

------------------------------------------------------------------------

# 五、广告数据接口示例

``` json
{
 "code":0,
 "data":[
   {
     "ad_id":"1001",
     "title":"Super Mario",
     "icon":"https://cdn.xxx/icon.png",
     "cover":"https://cdn.xxx/cover.png",
     "desc":"经典马里奥游戏",
     "game_url":"https://game.xxx/play/1001",
     "open_type":"webview"
   }
 ]
}
```

字段说明：

  字段        说明
  ----------- ----------
  ad_id       广告ID
  title       游戏名称
  icon        游戏图标
  cover       封面
  desc        简介
  game_url    游戏地址
  open_type   打开方式

# 七、广告加载接口

Banner

``` kotlin
BannerAdView banner = new BannerAdView(context);
banner.loadAd("banner_ad_unit");
```

卡片广告

``` kotlin
CardAdView card = new CardAdView(context);
card.loadAd("card_ad_unit");
```

信息流广告

``` kotlin
FeedAdLoader loader = new FeedAdLoader(context);
loader.loadAd("feed_ad_unit", callback);
```

多卡片广告

``` kotlin
MultiCardAdView multi = new MultiCardAdView(context);
multi.loadAd("multi_card_unit");
```
